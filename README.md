# Weather App - Simple Version

## Cách sử dụng đơn giản (như ngày xưa)

1. **Mở bằng Live Server:**
   - Click chuột phải vào `index.html` → "Open with Live Server"
   - Hoặc mở trực tiếp `index.html` trong trình duyệt

2. **Hoặc mở trực tiếp:**
   ```
   Nhấp đúp vào index.html
   ```

## Chức năng

- ✅ Tìm kiếm thời tiết theo tên thành phố
- ✅ Hiển thị nhiệt độ, mô tả thời tiết, độ ẩm, áp suất
- ✅ Background image tự động đổi theo thành phố (Unsplash)
- ✅ Gợi ý 6 thành phố ngẫu nhiên
- ✅ Responsive trên mobile

## API Keys

- OpenWeather API: đã nhúng sẵn
- Unsplash API: đã nhúng sẵn
